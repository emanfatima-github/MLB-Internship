# Smart Object Detection Application

## Project Overview

This project is a Smart Object Detection Application built using Streamlit and the YOLOv8 model from Ultralytics.

Users can upload images or videos, perform object detection, view detected objects with bounding boxes, see class names and confidence scores, 
and download the processed results.

## Features

* Upload image files
* Upload video files
* Object detection using YOLOv8
* Display bounding boxes
* Show class names
* Show confidence scores
* Download processed images
* Download processed videos

## Technologies Used

* Python
* Streamlit
* Ultralytics YOLOv8
* OpenCV
* Pillow

## Run Application

streamlit run app.py
